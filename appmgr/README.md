# Appmgr：xApp 镜像来源真实性问题（RIC-1078）

研究对象：O-RAN SC `ric-plt-appmgr` 中的 `xapp_onboarder 1.0.0`。
这里对应此前讨论的“下载镜像/镜像来源校验”问题。目录整理日期：2026-11-03。

## 问题与结论边界

所审查的 onboarding 路径先验证描述符结构，再生成并分发 Helm Chart。
描述符可指定镜像 registry、name、可变 tag 及容器 command、args；记录的疑点是
组件内未建立受信发布者、描述符和实际镜像内容之间的签名与不可变内容绑定。

现有材料支持“固定源码路径中的真实性校验缺失”观察，尚未证明受支持部署中
存在可被低信任主体跨越的权限边界。若入口只对等价部署权限的管理员开放，
或外部验签/准入检查强制有效，最终漏洞认定可能不同。
